# Tournepage

Leitor EPUB desktop para macOS, Windows e Linux, com biblioteca por pastas e uma experiência de leitura inspirada no [L’Essentiel](https://github.com/BrunodosSantosVaz/lessentiel).

**Estado: preparação do desenvolvimento.** O aplicativo ainda não foi implementado; não há instalador ou release do Tournepage disponível.

A [especificação fornecida pelo dono](<Leitor EPUB — Especificação de Desenvolvimento.md>) inclui o adendo dos três ambientes: desenvolvimento local rápido, homologação e produção. O [roteiro do modelo executor](.agents/tournepage/EXECUCAO.md) e o [backlog](.agents/tournepage/BACKLOG.md) organizam a implementação.

A [identidade visual v1.0](<Tournepage Identidade Visual.dc.html>) foi fornecida como referência; seu [inventário para implementação](.agents/tournepage/IDENTIDADE-VISUAL.md) organiza marca, cores, tipografia e ícones.

Rust + Iced, renderização nativa sem webview, dados locais e EPUBs originais intocados são as escolhas do plano. O projeto usa o framework [Big Bang](https://github.com/BrunodosSantosVaz/big-bang), cuja Fundação e esteira do sistema ainda precisam ser concluídas.

A Wiki está habilitada e aguarda inicialização; Discussions e o Project do Tournepage ainda precisam ser configurados na Fundação. Os links serão publicados quando esses espaços estiverem disponíveis.
